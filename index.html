作者簡介

「雷電」代理人自 2026 年創立以來，足跡只在 Line，我是製作人，目的是我們可以有更生活化的方式使用人工智慧，使人工智慧技術輕鬆地融入我們的生活中。

  • 「雷電」會講笑話
  • 「雷電」可以讀懂天氣
  • 「雷電」即將可以推薦你宵夜要吃什麼

本專案使用 Python 製作，結合 LINE Messaging API、天氣資料解析與 Render 部署。
此說明頁則使用 HTML、CSS、Bootstrap 與 JavaScript 製作，作為雷電 LINE Bot 的官方入口網站。
