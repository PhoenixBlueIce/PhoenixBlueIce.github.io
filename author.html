《陋站銘》序

余觀今之習程式者，或汲汲於框架之新，或惶惶於語言之眾。終日伏案，鍵聲鏗鏘，雖無琴書之雅，實有造化之功。
然世人多視碼農為苦役，殊不知其中亦有樂趣存焉。夫陋室可銘，陋碼亦可銘也。
不揣淺陋，戲作數語，以誌 coding 之甘苦。非敢言志，聊博同儕一笑云爾。

《陋站銘》

碼不在多，能跑則行；腦不在強，有肝則贏。斯是陋站，唯吾更新。
專案上線通，日誌一片青；除錯有工具，往來無白工。可以談培森，論模型。
無爆炸之代碼，無健康之煩憂。開放原始碼，自由軟體魂。編譯器云：何錯之有？

我習慣以系統化方式拆解問題，先建立可運作的第零版，再逐步重構資料流、錯誤處理與使用者體驗。
「雷電」是我用 Python 製作的 LINE Bot 作品，負責整合文字指令、天氣資料與回覆邏輯；
而這份「官方說明書」則是為了補足作品展示與使用說明，讓功能不只存在於程式碼中，也能被使用者理解與操作。

《涼週詞》

珍珠奶茶飲料杯，欲飲手機馬上催。倒臥床鋪君莫笑，古來加班幾人回？

《將體檢》(片段)

君不見，錯誤之潮天上來，奔流入海不復回。
君不見，體檢報告之紅字，昔如綠碼今成朱。

如果有人問我為什麼要學程式、寫 code，我的答案其實很簡單：因為我本來就對這件事有興趣。
我認為寫程式是一件比較有趣的事情，在電腦的世界中，我可以像「造物主」一樣建立規則、設計流程，讓資料與功能依照自己的邏輯運作。
現在有了 AI 作為輔助，我覺得現代工程師更應該懂得勞逸結合：該專注時專注，該休息時也要好好休息。
休息是為了走更長遠的路，健康是一切的根本。

《將體檢》(片段)

工作放假須盡休，莫使指數乾上升。
天生我材必有用，專案進度莫擔心。
遊山玩水且為樂，環遊世界八十天。

我希望自己的作品不只是能執行，也能被理解、被使用、被記住。
「雷電」是我從 Python、API 串接與前端展示開始建立的作品之一，而這份官方說明書則是我嘗試把功能、文件與個人風格整合在一起的成果。
我重視作品的可維護性與可解釋性，也相信該正經的地方就要正經；但生活本來就有壓力，難得能在作品裡保留一點幽默與創意，我認為那也是讓人持續前進的一種方式。

在技術實作上，「雷電」主要使用 Python 撰寫，結合 LINE Messaging API、Flask、JSON 資料處理與天氣資料解析；
而這份「官方說明書」則使用 HTML、CSS、Bootstrap 與 JavaScript 製作，作為作品展示與使用者操作入口。
